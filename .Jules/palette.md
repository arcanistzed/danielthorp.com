## 2024-03-01 - Skip-to-content Implementation
**Learning:** For visually hidden but focusable elements (like skip-to-content links), use a specific class like `.skip-link` for focus styles (`:focus`, `:focus-visible`) rather than globally modifying `.sr-only:focus`, which can unintentionally reveal other screen-reader-only elements when they receive focus. Furthermore, to ensure screen readers can correctly process this jump, the target container (e.g. `<main>`) must have `tabindex="-1"` for programmatic focus, and `#content:focus { outline: none; }` should be maintained to prevent unwanted visual browser outlines on jump.
**Action:** Always implement a dedicated class for skip-link focus styles instead of modifying `.sr-only:focus`. Ensure skip link target elements have `tabindex="-1"` and `outline: none` when focused.
