## 2026-08-17 - Added sr-only class for external links\n**Learning:** Astro projects that rely on standard HTML anchors with target='_blank' often lack context for screen reader users that the link will open in a new tab. While social icons here had aria-labels, text links didn't.\n**Action:** Implemented a standard .sr-only class in base.css and added it to external links to provide the necessary context to screen readers without altering the visual design.
