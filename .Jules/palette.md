## 2024-11-20 - Skip-link focus management
**Learning:** When creating a skip-to-content link targeting a `<main>` container, it is essential to ensure screen readers properly process the jump. To do so, the target `<main>` element must be given `tabindex="-1"` so it can be programmatically focused, and CSS must remove the focus outline on the main element (`#content:focus { outline: none; }`) to prevent an unwanted visual browser outline on jump. The skip-to-content element needs to be made visible on `:focus` / `:focus-visible` to aid keyboard users without revealing other screen-reader-only content.
**Action:** Always add `tabindex="-1"` and prevent focus outlines on skip-link target elements. Use specific classes like `.skip-link` for focus styles instead of broadly modifying `.sr-only:focus`.
